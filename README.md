# Organização de Desenvolvimento Sustentável

##  Sobre o Projeto

O projeto **Organização de Desenvolvimento Sustentável** é um site institucional voltado à **promoção do desenvolvimento sustentável**, com foco em **educação ambiental, inclusão social e responsabilidade ecológica**.

O site conta com:
- **Modo escuro (Dark Mode)** com alternância dinâmica;
- **Projetos** indicando os principais projetos;
- **Formulários de contato e doação** com validação;
- **Acessibilidade conforme WCAG 2.1 Nível AA**;
- **Layout responsivo**, adaptável a diferentes tamanhos de tela.

---

##  Funcionalidades

- Página inicial com informações sobre o tema  
- Formulário de contato com validação  
- Página de doações  
- Alternância entre **modo claro e escuro**  
- Layout responsivo (desktop e mobile)  
- Padrão **WCAG 2.1 AA** de acessibilidade  
- Controle de versão seguindo **GitFlow**

##  Acessibilidade (WCAG 2.1 AA)

O projeto segue as recomendações da **WCAG 2.1 Nível AA**, garantindo:
- Contraste mínimo de **4.5:1** entre fundo e texto;  
- Textos alternativos (`alt`) em todas as imagens;  
- Estrutura semântica com uso de `<header>`, `<main>`, `<section>`, `<footer>`;  
- Navegação funcional por teclado;  
- Elementos de formulário acessíveis (`label`, `fieldset`, `legend`).
